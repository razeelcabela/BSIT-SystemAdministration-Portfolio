# Week 2 – Enterprise Infrastructure Planning

## Project Overview

This project presents an **Enterprise Infrastructure Plan for ABC Startup Solutions**, a startup software development company with 20 employees.

The project covers hardware, software, networking, system administration roles, security, backup strategies, and infrastructure recommendations.

For the complete documentation, see:

📄 **[Enterprise Infrastructure Plan](EnterpriseInfrastructurePlan.pdf)**

---

## Learning Objectives

This project helped me practice:

* IT infrastructure planning
* Hardware and software inventory
* Network planning and design
* System administration concepts
* Security and backup planning
* Technical documentation using Markdown and GitHub

---

## Company Scenario

**ABC Startup Solutions** is a newly established software development company with **20 employees**.

| Department             | Employees |
| ---------------------- | --------: |
| Information Technology |         5 |
| Human Resources        |         4 |
| Finance                |         5 |
| Sales                  |         6 |
| **Total**              |    **20** |

The company initially has no computers, servers, network infrastructure, internet infrastructure, or security policies.

---

## Inventory Summary

The proposed infrastructure includes:

**Hardware**

* Desktop computers and laptops
* Server
* NAS storage
* Monitors and printers
* UPS units

**Software**

* Windows 11 Pro
* Ubuntu Server
* Microsoft Office
* Visual Studio Code
* Git and GitHub Desktop
* VirtualBox
* Microsoft Defender
* AnyDesk
* 7-Zip

**Network**

* ISP Modem / ONT
* Router
* Firewall
* Managed Switch
* Wireless Access Points
* CAT6 cabling
* Patch panels

Detailed inventories and explanations are available in the **Enterprise Infrastructure Plan PDF**.

---

## Network Diagram

![ABC Startup Solutions Network Topology](diagrams/ABC-Network-Topology.png)

The proposed network follows the basic structure:

**Internet → ISP Modem/ONT → Router → Firewall → Managed Switch → Company Devices**

The network connects the IT, Human Resources, Finance, and Sales departments together with the server, printers, NAS, and wireless access points.

## Challenges Encountered

The most challenging part of the project was designing the enterprise network topology and selecting appropriate equipment for a 20-employee startup company.

The activity helped me understand how different hardware, software, and networking components work together in an organization.

---

## Reflection

This project helped me understand the importance of planning an IT infrastructure before deployment. I learned that a System Administrator must consider hardware, software, networking, security, backups, and future expansion when designing an IT environment.

The complete reflection is included in the **Enterprise Infrastructure Plan PDF**.
