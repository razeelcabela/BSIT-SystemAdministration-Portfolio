Challenges Encountered

1. Choosing the Correct Software Version

One of the challenges I encountered was determining which version of the required software was compatible with my computer. Some applications had different versions depending on the operating system and system architecture. I solved this problem by checking my computer's system information and downloading the appropriate installer from the official website.

2. Account Verification and Setup

Another challenge I encountered was completing the verification process when creating my professional accounts. Some accounts required email confirmation and additional profile information before they could be fully activated. I solved this by checking my registered email, following the verification link, and completing the required information on my profile.

3. Organizing Files and Folders in GitHub

At first, I found it challenging to understand how folders and files are created and organized inside a GitHub repository. I learned that GitHub does not normally keep empty folders, so a file such as `README.md` must be created inside a folder. I solved this by following the required repository structure and using proper file and folder names.

Reflection

During this activity, I learned how important it is to prepare a proper professional and technical environment before performing system administration tasks. Installing the required software gave me a better understanding of the different tools that can be used for programming, version control, documentation, and virtualization. I also learned that software should be downloaded from official websites to ensure that the installer is legitimate, updated, and safe to use.

Creating my GitHub and LinkedIn accounts also helped me understand the importance of maintaining a professional online presence. GitHub allows me to organize and document my activities, projects, and technical work in one place, while LinkedIn can be used to present my educational background, skills, and future professional experience. I also learned how to create a GitHub repository, organize folders, upload files and screenshots, edit a README file, and commit changes.

The challenges I encountered during the activity also improved my problem-solving skills. Instead of immediately giving up when I encountered installation or account setup problems, I learned to carefully review instructions and look for appropriate solutions.

These skills will support my development as a future System Administrator because the profession requires proper documentation, organization, troubleshooting, software management, and continuous learning. This activity provided me with a useful foundation that I can apply to future laboratory exercises and real-world IT tasks.
